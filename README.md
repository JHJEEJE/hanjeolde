# 🪷 한 절 더 — AI가 짜 주는 경주 사찰 순례길 (새 시제품)

사찰 QR을 찍거나 출발지를 고르고, **누구랑(7) · 시간(30분~5시간 슬라이더) · 걷기 정도(4) · 관심사(10개, 여러 개)** 와
**AI에게 자유롭게 말하기**(예: "선덕여왕 이야기가 궁금하고 오르막은 싫어요")를 쓰면, AI가 35곳 중에서 그 사람에게 맞는 도보 순례길을 새로 짜 줘요.
걷는 동안 이야기 조각을 모으고, 구간마다 가깝고 평 좋은 카페·식당·공방을 추천하고, "볼 게 없어요"를 누르면 주변 대안으로 바로 바꿔 줘요.
끝나면 메모·기분·사진·배지가 담긴 **나만의 순례 일지**와 **순례 엽서(PNG)** 가 만들어져요.

## 화면 구조 (HTML 앱)
화면은 `web/` 폴더의 HTML 앱(휴대폰 모양 · 하단 탭 4개)이고, AI 계산은 파이썬이 해요. Streamlit 주소는 그대로예요.
- 🚶 **순례**: ① 출발지(AI가 정해요 / QR 장소 / 직접 고르기) ② 시간(5분 단위 슬라이더) ③ 일행 ④ 걷기 정도 ⑤ 관심사 ⑥ AI에게 하고 싶은 말 → AI 추천 3안 → 걷기 → 일지·사진 엽서
- 🗺️ **지도**: 35곳을 종류별 아이콘 핀으로, 누르면 소개와 '여기서 시작하기'
- 🧪 **AI 비교**: 같은 취향으로 시각(09:30·13:00·15:30·16:30) × 날씨(맑음·비·영하·폭염) 16가지 추천을 한 화면에 (포스터용 목업 겸 실제 화면)
- 📊 **기록**: 구간별 완주율 → 가장 많이 멈춘 구간 → 자동 보완 → 보완 전후 비교 (가상 데이터 80건)
- ⚙️(오른쪽 위): 발표 설정 — 날씨·시각·계절을 바꿔 시연
- 예전 Streamlit 화면은 `app_classic.py`에 남겨 뒀어요.

| 파일 | 하는 일 |
|---|---|
| `web/index.html` · `web/app.js` · `web/style.css` | 화면 (HTML·JS) |
| `web/postcard.js` | 사진 엽서 그리기 (사진 없으면 그림 엽서) |
| `web/leaflet.*` | 지도 라이브러리 (BSD-2, 파일로 넣어 둠) |
| `webapp.py` | 화면 ↔ AI 엔진 연결 (요청: plan · route · alts · finish · compare) |

## AI가 하는 일 (포스터용 요약)
| 단계 | 무엇을 | 방법 (코드) |
|---|---|---|
| ① 취향 이해 | 선택지 + 자유 입력 → 9개 테마 가중치, 오르막 피하기, 카페 원함, 꼭 넣을 곳 | 4개 언어 규칙 해석 + (키 있으면) Claude Haiku 해석 — `planner.understand` |
| ①-1 출발지 | 'AI가 정해요'면 35곳 중 출발 후보 6곳(자기 점수 + 걸어서 닿는 주변 점수)을 골라 각각 경로를 짜고 비교 | `planner.pick_starts` |
| ② 후보 고르기 | 35곳마다 '나에게 맞는 정도' 점수 (테마 × 가중치 + 날씨·계절·일몰·조용함) | `planner.place_utility` |
| ③ 경로 최적화 | 시간·거리·체력 제약 안에서 점수 합이 가장 큰 순서 찾기 (오리엔티어링 문제, 후보 12곳 전수 탐색) | `planner.search` |
| ④ 다양한 3안 | 겹치지 않는 상위 3개 경로 + 이유 설명 | `planner.diverse_top`, `planner.explain` |
| ⑤ 에이전트 선택 | (키 있으면) Claude Sonnet이 도구로 후보·날씨·이야기를 확인하고 하나 골라 이유를 말해 줌 | `planner.agent_pick` |
| ⑥ 가게 추천 | 길에서 떨어진 거리 + 베이즈 평균 평점(리뷰 수 반영) + 시간대·날씨·일행 맞춤, 구간마다 겹치지 않게 | `shops.score`, `shops.assign` |
| ⑦ 볼 게 없어요 | 지금 위치 1.6km 안, 내 취향 점수가 높은 다른 곳으로 다음 목적지 교체 + 주변 공방·카페 | `shops.alternatives`, `shops.around` |
| ⑧ 일지 | 도착·메모·기분·사진·미션·길 바꿈을 장소 이야기와 엮은 **동화책 같은 한 편의 일기** + 사진 엽서, (키 있으면) Claude가 문장 다듬기 | `journal.story`, `web/postcard.js` |

화면의 **🔍 AI가 이 길을 고른 과정**을 펼치면 가중치 막대, 후보 점수표, 검토한 경로 수가 보여요. 포스터 시연 때 이걸 보여 주면 돼요.

### 포스터 시연 순서 (3분)
1. 같은 분황사에서 **관심사만 바꿔** 두 번 추천 → 길이 달라지는 것 보여 주기 (예: '사진 명소' vs '불상·불교미술 + 산길도 좋아요')
2. 자유 입력에 "선덕여왕 이야기, 오르막 싫어요, 카페에서 쉬고 싶어요" → 이유 줄에 ‘선덕’ → 인물 이야기 ↑ 등이 뜨는 것
3. 걷기 화면에서 **😐 볼 게 없어요** → 대안으로 교체, **😮‍💨 힘들어요** → 길 줄이기
4. 마치고 **일지 + 엽서** 내려받기, 언어를 English로 바꿔 같은 화면 보여 주기

## 4. 다국어 (한국어 · English · 日本語 · 中文)
- 화면 위 🌐 언어 목록에서 고르거나, 주소 뒤에 `&lang=en` / `ja` / `zh`를 붙이면 그 언어로 열려요.
  예: `https://○○○.streamlit.app/?temple=bunhwangsa&lang=en`
- 사이드바 **QR 만들기**에서 'QR 언어'를 고르면 외국어 안내판용 QR이 나와요.
- 바뀌는 것: 버튼·안내 문구, 사찰 이름·소개, 시대, 코스 이름, 이야기 조각·차이 한 줄·미션·계절 조각, 추천 이유, 일지, 기록 분석, 🔊 음성(언어별 발음).
- 출처(한국민족문화대백과사전)는 한국어 자료라서 사전 이름만 번역하고 '(in Korean)'을 붙여요.
- 사이드바(발표 설정)는 팀용이라 한국어 그대로예요.
- 한국어 원문을 고치면 `data/translations.json`의 번역도 같이 고쳐 주세요. 화면 문구는 `i18n.py`에 있어요.

## 5. 기상청 단기예보 · TourAPI 연결 — 선택
공공데이터포털(data.go.kr)에서 「기상청_단기예보 조회서비스」와 「한국관광공사_국문 관광정보 서비스_GW」를 활용신청하고,
**일반 인증키**를 Streamlit Secrets에 넣어요. (키는 둘 다 같아요. 저장소가 Public이니 파일에는 절대 적지 마세요.)
```
DATA_GO_KR_KEY = "공공데이터포털 일반 인증키"     # 둘 다 같은 키면 이 한 줄로 끝

# 서비스별로 키가 다르면 따로 넣어도 돼요 (있으면 위 공통 키보다 먼저 써요)
KMA_API_KEY  = "기상청 단기예보 키"
TOUR_API_KEY = "한국관광공사 국문 관광정보 서비스_GW 키"
```
- 사이드바 '🔑 API 키' 칸에 붙여 넣어도 바로 써 볼 수 있어요. 지금 접속에서만 쓰고 저장되지 않아요.
- 사이드바 '연결 상태'에서 키를 어디서 찾았는지, TourAPI가 몇 곳을 받아왔는지 보여 줘요.
- 기상청: 초단기실황(기온·강수형태)과 단기예보(앞으로 3시간 강수확률·하늘상태)를 써요. 강수확률 60% 이상이면 실내 마무리 길을 먼저 골라요.
- TourAPI: 순례길 장소마다 반경 1km 음식점·카페를 불러와 쉼터로 보여 줘요 ('관광공사' 표시). 팀이 직접 확인한 rest_spots.csv가 있으면 그게 먼저 나와요.
- 키가 없거나 아직 작동 전이면(발급 후 약 1시간) Open-Meteo·일몰 계산값·예시 쉼터로 알아서 돌아가요. 사이드바 '연결 상태'에서 확인할 수 있어요.

## 5-1. Google Places (가게 평점·리뷰 수) — 선택
리뷰 수·평점으로 가게를 고르려면 Google Cloud에서 **Places API (New)** 를 켜고 키를 넣어요. (결제 계정 등록 필요, 매달 무료 사용량 있음)
```
GOOGLE_PLACES_KEY = "AIza..."
```
키가 없으면 TourAPI(관광공사 등록 음식점·카페·쇼핑·문화시설) + 거리·시간대·날씨로만 추천하고, 화면에 평점은 안 보여요.

## 5-2. AI(Claude) 연결 — 선택
키가 없어도 모든 기능이 **규칙 기반 AI**로 돌아가요 (발표 중 인터넷이 끊겨도 안전).
키를 넣으면 자유 입력 해석(Haiku), 순례길 최종 선택과 이유(Sonnet 도구 호출 에이전트), 일행 맞춤 말투, 일지 문장을 Claude가 맡아요. 고른 언어로 답해요.
Streamlit Cloud → Manage app → Settings → Secrets:
```
ANTHROPIC_API_KEY = "sk-ant-..."
AGENT_MODEL = "claude-sonnet-5-5"   # 순례길 에이전트 (생략 가능)
FAST_MODEL = "claude-haiku-5-5"     # 말투·일지 (생략 가능)
```

## 6. 참가서류 5번과 연결
| 5번 | 화면 | 코드 (logic.py) |
|---|---|---|
| ① AI 순례길 추천 | 부탁하기 → 추천 카드 + 고른 이유 + AI 과정 | `planner.plan` (`understand` → `search` → `agent_pick`) |
| ② 날씨 자동 설정 | 추천 이유의 날씨·일몰 줄, 실내 마무리 | `get_conditions`, `time_budget` |
| ③ 코스 유형별 계산 | 구간별 시간(토블러), 구간별 AI 가게 추천 | `leg_info`, `tobler_kmh`, `shops.assign` |
| ④ 스토리텔링·음성 | 차이 한 줄 · 관심사별 이야기 · 출처 · 🔊 · 미션 · 계절 조각 | `story_for`, `diff_line`, `teaser`, `mission_for`, `season_for` |
| ⑤ 일지·다음 순례 | 일지(이야기·타임라인·메모·사진·배지) · 엽서 · 비슷한/새로운 코스 | `journal.*`, `recommend` |
| ⑥ 중단 분석·보완 | 순례 기록 탭: 구간 완주율 → 보완 제안 → 전후 비교 | `segment_table`, `make_virtual`, `suggestion` |

- 실제 기록은 `logs/pilgrim_log.json`에 쌓여요 (Streamlit Cloud는 앱이 다시 켜지면 지워져요).
- 가상 기록은 화면에서만 만들어지고 실제 기록과 섞이지 않아요. 화면에 '가상 데이터' 표시가 붙어요.

## 7. 팀이 채울 데이터
1. **story_pieces.json**: 문장을 출처와 대조한 뒤 `"verified": true`로 바꾸면 화면의 '검수 중'이 '✔ 출처 확인'으로 바뀌어요.
2. **rest_spots.csv**: 분황사 일대 쉼터 5~6곳. 칸: `id,name,type,lat,lon,open,close,closed_day,indoor,near_poi,partner,coupon,source,checked_date`
   (예: `cafe01,가게이름,카페,35.84,129.23,10:00,21:00,월,Y,bunhwangsa,후보,,카카오맵,2026-11-12`)
   `partner`가 `후보`면 '제휴 예정' 배지가 붙어요.
3. 이야기 조각을 다른 코스로 늘리려면 story_pieces.json의 `pieces`에 같은 형식으로 추가하세요.
